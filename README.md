# Игра сапёр

Сапёр, рассчитанный на невизуальное прохождение: NVDA на компьютере,
VoiceOver на айфоне, TalkBack на Android. Вся информация о клетке
произносится словами, поле видеть не нужно.

Играть: https://r1bqe.github.io/saper-game/

Поле 10 на 10, 10 мин. Выиграть можно, только разминировав все 10 мин.

## Управление

Клавиатура: стрелки — перемещение курсора, Ctrl со стрелкой — прыжок к краю,
Пробел — открыть клетку, Enter — разминировать, P — повторить последний ход,
T — сколько времени идёт партия.

Мышь: левая кнопка — открыть, правая — разминировать.

Жесты: короткое касание — открыть, касание с удержанием (от половины
секунды) — разминировать.

## Как запустить локально

Скачать папку и открыть `index.htm`. Игра собирается из ES-модулей, поэтому
файлом с диска она не заработает — нужен веб-сервер. На Windows для этого
лежит `StartServer.bat`: он поднимает сервер на порту 8000 и открывает игру
в Chrome.
